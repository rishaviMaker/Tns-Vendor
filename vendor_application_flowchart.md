# Vendor Application Architecture Flow Chart

This document contains a comprehensive flow chart of the Vendor Application architecture in Mermaid format.

To visualize this flow chart:

1. Copy the contents of `vendor_application_flowchart.mermaid`
2. Visit [Mermaid Live Editor](https://mermaid.live/)
3. Paste the code into the editor
4. You'll see a professional visualization of your application architecture

The flow chart includes:

- Client Applications (Mobile and Web)
- API Gateway & Authentication
- Route Handlers
- Controllers
- Business Services
- Data Models
- External Services
- Database
- Authentication Flow
- Notification System Flow
- Dashboard Data Flow
- Order Processing Flow
- Coupon Management System

**Key Features Visualized:**

1. **Authentication System**: JWT token verification flow
2. **Notification System**: Event triggers to Firebase delivery
3. **Dashboard System**: Data aggregation from multiple models
4. **Order Processing**: Complete order lifecycle
5. **Coupon Management**: Creation, validation and application of discounts

This visualization will be useful for:
- Onboarding new developers
- Planning system expansions
- Identifying dependencies
- Documentation purposes
