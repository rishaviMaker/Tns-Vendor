  "confirmPassword": "securePassword123",

## 2. Send OTP

**URL:** `POST /api/vendors/send-otp`

**Payload:**
```json
{
  "mobileNumber": "9876543210",
  "deviceToken": "firebase-device-token-for-push-notification"
}
```

**Response:**
```json
{
  "status": "success",
  "message": "OTP sent successfully"
}
```

## 3. Verify OTP

**URL:** `POST /api/vendors/verify-otp`

**Payload:**
```json
{
  "mobileNumber": "9876543210",
  "otp": "123456",
  "vendorId": 1
}
```

**Response:**
```json
{
  "status": "success",
  "message": "OTP verified successfully"
}
```
