# PRODUCT API DOCUMENTATION

## Authentication
All endpoints require authentication using JWT token in the Authorization header:
```
Authorization: Bearer your-jwt-token
```

## 1. Create Product
**URL:** `POST /api/products/create`  
**Content-Type:** `multipart/form-data` (for file uploads)  
**Authentication:** Required  

### Request Payload:
```
Form Data:
- name: "Product Name" (required)
- description: "Product description text"
- content: "Detailed product content"
- status: "pending" (default if not specified)
- sku: "SKU123456"
- order: 1
- quantity: 100
- allow_checkout_when_out_of_stock: false
- with_storehouse_management: true
- is_featured: false
- brand_id: 1
- is_variation: false
- sale_type: 0
- price: 99.99
- sale_price: 79.99
- start_date: "2025-06-01T00:00:00Z"
- end_date: "2025-07-01T00:00:00Z"
- length: 10.5
- wide: 5.2
- height: 2.0
- weight: 1.5
- tax_id: 1
- stock_status: "in_stock" (default if not specified)
- category: "Electronics"
- sub_category: "Mobile Phones"
- purchase_price: 75.00
- hsn_sac_code: "HSN12345"
- applicable_tax: "GST18"
- unit: "Piece"


File Fields:
- images: Multiple image files (up to 10)
- videos: Multiple video files (up to 5)
```

### Response (Success - 201):
```json
{
  "status": "success",
  "data": {

      "sku": "SKU123456",

      "with_storehouse_management": true,

      "length": 10.5,
```

## 2. Get All Products
**URL:** `GET /api/products`  
**Authentication:** Not required (public endpoint)  

### Query Parameters:
```
store_id=1 (optional, filter by store)
limit=10 (optional, default: 10)
page=1 (optional, default: 1)
```

### Response (Success - 200):
```json
{
  "status": "success",
  "results": 5,
  "total": 25,
  "totalPages": 3,
  "currentPage": 1,
  "data": {
    "products": [
      {
        "id": 1,
        "name": "Product Name",
        "description": "Product description",
        "status": "published",
        "price": 99.99,
        // ... other product fields
      },
      // ... more products
    ]
  }
}
```

## 5. Update Product
**URL:** `PATCH /api/products/update/:id`  
**Content-Type:** `multipart/form-data` (for file uploads)  
**Authentication:** Required  

### Request Payload:
Same fields as Create Product (all fields optional)

### Response (Success - 200):
```json
{
  "status": "success",
  "data": {
    "product": {
      "id": 1,
      "name": "Updated Product Name",
      // ... other updated fields
      "updated_at": "2025-05-30T05:15:22.000Z"
    }
  }
}
```

### Response (Error - Product Not Found - 404):
```json
{
  "status": "fail",
  "message": "Product not found"
}
```

## 7. Update Product Status
**URL:** `PATCH /api/products/status/:id`  
**Content-Type:** `application/json`  
**Authentication:** Required  

### Request Payload:
```json
{
  "status": "published"  // Options: "published", "pending", "draft"
}
```

### Response (Success - 200):
```json
{
  "status": "success",
  "message": "Product status updated to published",
  "data": {
    "product": {
      "id": 1,
      "status": "published",
      // ... other product fields
      "updated_at": "2025-05-30T05:18:45.000Z"
    }
  }
}
```

### Response (Error - Invalid Status - 400):
```json
{
  "status": "fail",
  "message": "Invalid status value. Must be one of: published, pending, draft"
}
```

```json
{
```

```json

  "status": "error",
  "message": "Error message details"
}
```

## File Upload Notes

1. Images are stored in `/uploads/products/` directory
2. Videos are stored in `/uploads/products/videos/` directory
3. Maximum image upload: 10 files per request
4. Maximum video upload: 5 files per request
5. Maximum file size: 50MB
6. Supported image formats: All standard image formats (jpg, png, gif, etc.)
7. Supported video formats: All standard video formats (mp4, mov, etc.)
